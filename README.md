# Tanya Kumari — Personal Portfolio

A responsive, dark-themed developer portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, run a local static server (for example, VS Code Live Server).
3. The profile photograph is stored at `assets/tanya-portrait.png`.

## Deploy for free
### Vercel
1. Create a GitHub repository and upload the contents of this folder.
2. Import the repository into Vercel.
3. Choose the static/Other framework preset and deploy. No build command is required.

### Netlify
Drag the extracted folder into Netlify's manual deploy area, or connect the GitHub repository.

## Before publishing
- Add a resume PDF file and update the hero's “Download resume” CTA if you want an actual download button. It is intentionally not linked to a nonexistent file yet.
- Add certificate verification links where available.
- Review the project metrics and internship descriptions for accuracy.
- This portfolio links to GitHub repositories; no live project deployment URLs were supplied.
- Replace the placeholder “Open to opportunities” status if it does not match your current situation.
