# Tanya Kumari Portfolio — fixed version

## Fixes included
- Profile photo embedded directly in `index.html`, so it still loads if an `assets` folder is accidentally omitted during upload.
- Added gentle animated orbit rings, floating tech chips, a light sweep, and pointer-responsive 3D tilt around the portrait.
- Added a LinkedIn profile link in the contact section and footer: https://www.linkedin.com/in/tanyadev-kumari
- Kept responsive design and reduced-motion accessibility support.

## Deploy the fix to Vercel
1. Extract this ZIP.
2. Open your GitHub repository connected to Vercel.
3. Click **Add file → Upload files**.
4. Upload/replace `index.html`, `styles.css`, and `script.js` from this folder.
5. Commit changes. Vercel should redeploy automatically.
6. Refresh your site with Ctrl+F5 if the old version remains cached.

The LinkedIn link uses the profile URL supplied in the resume rather than the generic LinkedIn feed URL. Update it if your preferred profile URL differs.
